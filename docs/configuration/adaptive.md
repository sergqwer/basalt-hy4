# Adaptive expert tier

Qwen3.8-Flash-Next's and was removed with it; Hy4-flash takes none of these flags. Its main card's expert copies give way by
use instead ([memory](../models/hy4-flash.md#memory)). The upstream page:
[adaptive tier](https://github.com/jesdga95/basalt/blob/a11e19f6/docs/configuration/adaptive.md).
